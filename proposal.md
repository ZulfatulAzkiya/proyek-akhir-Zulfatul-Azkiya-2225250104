# PROPOSAL PROYEK
# PROGRAM ANALISIS NILAI SISWA MENGGUNAKAN PYTHON

## 1. Latar Belakang

Pengolahan nilai merupakan salah satu kegiatan yang sering
dilakukan dalam dunia pendidikan. Guru perlu mengolah nilai
untuk mengetahui hasil belajar siswa.

Jika pengolahan nilai dilakukan secara manual, prosesnya
dapat membutuhkan waktu yang cukup lama dan berisiko
menimbulkan kesalahan perhitungan.

Oleh karena itu, diperlukan sebuah program sederhana yang
dapat membantu proses pengolahan dan analisis nilai siswa
secara otomatis menggunakan bahasa pemrograman Python.

## 2. Tujuan Proyek

Tujuan dari pembuatan program ini adalah:

1. Membuat program untuk mengolah data nilai siswa.
2. Menghitung rata-rata nilai siswa secara otomatis.
3. Menentukan nilai tertinggi dan nilai terendah.
4. Menghitung jumlah siswa yang lulus dan tidak lulus.
5. Menerapkan penggunaan fungsi dan modul Python.

## 3. Manfaat Proyek

Program ini diharapkan dapat membantu pengguna dalam
mengolah data nilai siswa dengan lebih mudah, cepat,
dan terstruktur.

Selain itu, proyek ini dapat meningkatkan pemahaman
mengenai penggunaan bahasa Python dalam menyelesaikan
permasalahan sederhana.

## 4. Gambaran Program

Program Analisis Nilai Siswa merupakan aplikasi berbasis
teks yang digunakan untuk membaca dan mengolah data nilai.

Data siswa terdiri dari nama dan nilai. Data tersebut
kemudian diproses untuk menghasilkan informasi berupa
rata-rata nilai, nilai tertinggi, nilai terendah,
jumlah siswa lulus, dan jumlah siswa tidak lulus.

## 5. Fitur Program

Fitur yang direncanakan dalam program ini meliputi:

1. Membaca data nilai siswa dari file.
2. Memvalidasi data nilai.
3. Menghitung rata-rata nilai.
4. Menentukan nilai tertinggi dan terendah.
5. Menghitung jumlah siswa yang lulus.
6. Menghitung jumlah siswa yang tidak lulus.
7. Menyimpan hasil analisis ke dalam file.

## 6. Teknologi yang Digunakan

- Bahasa pemrograman: Python.
- Editor: Visual Studio Code.
- Penyimpanan data: File TXT.
- Version control: Git dan GitHub.

## 7. Pembagian Modul Program

Program dibagi menjadi beberapa file agar lebih mudah
dikembangkan dan diperbaiki.

- main.py: Mengatur jalannya program.
- data_io.py: Mengatur proses membaca dan menyimpan data.
- analisis.py: Mengolah dan menghitung data nilai.
- utilitas.py: Menyediakan fungsi bantuan program.

## 8. Hasil yang Diharapkan

Program dapat berjalan dengan baik dan menghasilkan
informasi analisis nilai siswa secara otomatis.

Program juga diharapkan dapat menjadi contoh penerapan
dasar pemrograman Python dalam bidang pendidikan.
